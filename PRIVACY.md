# Privacy Policy – myTime to Calendar

**myTime to Calendar** is a Chrome extension that helps Target team members export their myTime work schedule to their personal calendar.

## Data Access
The extension reads schedule information (such as shift dates, times, role, and location) directly from the myTime website when the user is viewing their schedule. This data is used only to create calendar events or downloadable calendar files at the user’s request.

## Google Calendar Access
When the user chooses to add shifts to Google Calendar, the extension uses Google OAuth to authenticate the user and create calendar events. The extension does not access or store Google account passwords or credentials.

## Data Storage
The extension stores only basic user preferences (such as settings options) using Chrome’s extension storage. No work schedule data or personal information is stored persistently.

## Data Sharing
The extension does not sell, transfer, or share user data with third parties. No data is sent to external servers except to Google Calendar APIs when the user explicitly chooses to add events to their calendar.

## Remote Code
The extension does not execute remote code. All JavaScript logic is bundled with the extension package.

## Changes
This privacy policy may be updated if the extension’s functionality changes. Any updates will be reflected in this document.
